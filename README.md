# Bloom

A calm space adventure. You're stranded on a dead little planet, and a glowing bubble keeps you alive.
Gather wood, stone, crystal and gold, grow the bubble to bring the world back to life, rescue lost
astronauts, upgrade your tools and suit, and repair your rocket. No enemies, no way to lose.

**Play:** open this repository's GitHub Pages link on your phone in Chrome, then **Add to Home screen**.

Source is in `src/`. `npm install` then `npm run build` rebuilds the game into `dist/`; copy those files
to the repository root to publish. Design notes: `BLOOM_DEVNOTES.txt`.
